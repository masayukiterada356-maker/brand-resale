# フリマ下書き作成プログラム（自宅PC・Windows用）

アプリで「出品文OK」になった商品を、自宅PCのChromeで
**メルカリ → ラクマ → ヤフーフリマ** の順に、写真付きの**下書き**として保存します。

- 1枚目は黄色い枠のサムネイル、続けて外注さんの写真（ヤフーフリマは10枚まで）
- **「出品する」「公開」ボタンは絶対に押しません**（押す前にボタンの文字を確かめています）
- 終わった結果はアプリの商品画面の「フリマの下書き」に出ます
- カテゴリやブランドが選べなかった時も下書きは保存し、「要確認」として知らせます

## 初回の準備（1回だけ）

1. **Node.js** を入れる：https://nodejs.org から「LTS」をダウンロードしてインストール
2. この `agent` フォルダを `C:\flea-agent` に置く
3. `setup.ps1` を右クリック →「PowerShellで実行」
   - 必要な部品が入り、`config.json` ができ、タスクスケジューラーに「フリマ下書き作成」（毎晩1:13）が登録されます
4. `config.json` をメモ帳で開き、次を書き換える
   - `appUrl`：アプリのURL
   - `agentToken`：Cloudflareに設定した合言葉（AGENT_TOKEN）
   - `cfAccessClientId` / `cfAccessClientSecret`：Cloudflare Accessのサービストークン
5. フォルダの中でコマンドプロンプトを開き、`npm run login`
   - **このプログラム専用のChrome**が開きます。3つのフリマにログインしてから閉じてください（普段のChromeとは別なので、普段の作業には影響しません）
6. `npm run check` で、アプリとつながるか・ログインできているかを確かめる

## 毎晩の値下げ（フリマごとに時間帯と件数が決まっている）

| フリマ | 時間帯 | 1日の件数 |
|---|---|---|
| ラクマ | 19:00〜20:00 | 50件 |
| メルカリ | 21:00〜22:00 | 50件 |
| ヤフーフリマ | 22:00〜23:00 | 50件 |

- タスク「フリマ値下げ」が毎晩19:00に `run-price.bat` を動かし、23:59まで動き続けます
- 時間帯に入ったフリマの「出品中」の一覧を読み、アプリから今日の計画をもらって、ランダムな順・ばらばらの間隔で1件ずつ **100円** 下げます
- **損益分岐点より下には下げません**。編集画面の価格がアプリの記録と違う時は、その日は下げずに価格を覚え直します
- **PCが動いていなかった時**：タスク「フリマ値下げ（起動時）」がログインの3分後に動き、ラクマ・ヤフーフリマは**起動した時から取り戻します（ヤフーフリマが先）**。メルカリは取り戻さず、アプリの「値下げ」画面に手で下げる一覧が出ます
- 2つ同時には動きません（すでに動いている時は、2つ目はすぐ止まります）
- 記録：`logs\price.log`
- ※ 各フリマの「出品中の一覧」と「編集画面」のURL・目印は、本物の画面で最初に確かめる必要があります（`sites\*.mjs` の「要確認」）

## 売れた商品の止め忘れチェック（PCを起動した時）

- 売れた時は、アプリの在庫の画面の一番上に「**止める出品が◯件**」と赤く出ます。各フリマで止めて「止めた」を押します（ふだんは手動）
- PCにログインすると、3分後にタスク「フリマ起動時チェック」が `run-startup.bat` を動かします
  1. 3つのフリマの「出品中」の一覧を読み、アプリで「売れた」になっている商品がまだ出品中なら止めます（メルカリ・ヤフーフリマは停止、ラクマは下書きに戻す。**売れたフリマの出品と、削除ボタンには触りません**）
  2. 続けて、値下げの取り戻し（ラクマ・ヤフーフリマ）をします
- 手で動かす時：`npm run check-stops`
- 記録：`logs\startup.log`
- ※ 「停止」「下書きに戻す」のボタンの場所は、本物の画面で最初に確かめる必要があります

## 毎日の動き

- 毎晩1:13に `run.bat` が動き、最大5点（`maxItemsPerRun`）の下書きを作ります
- 1点ごとに1〜3分あけ、操作の間にも少し間をあけます
- パソコンがスリープしていると動きません（電源の設定で、夜はスリープしないようにしてください）
- 記録：`logs\run.log`、失敗した時の画面：`logs\*.png`

## うまく動かない時

- **ログインが切れた**：`npm run login` でログインし直す
- **フリマの画面が変わって失敗が続く**：Claude Code で `agent\sites\` の中の該当フリマのファイルを直します。`logs` の画面の記録を見せると早いです
- 同じ商品が3回失敗すると、その商品のそのフリマは自動では止めます。アプリの「やり直す」で再開できます

## 練習用の画面で試す（開発用）

本物のフリマに触らずに、練習用のニセの画面で動きを確かめられます。

```
set AGENT_FAKE_SITES=%CD%\test\fake-sites
npm run run
```
